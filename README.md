# WORDSHIFT 🎮

WORDSHIFT is a real-time multiplayer word transformation game where two players compete to turn one four-letter word into another.

## How to Play
- Player 1 creates a room and chooses a starting word.
- Player 2 joins through the invitation link and chooses the target word.
- Take turns changing exactly one letter at a time.
- Every word must be a meaningful English word.
- Reach the target word to win!

## Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js
- Socket.IO
- Tailwind CSS

## Features
- Real-time 2-player gameplay.
- Shareable room links.
- Turn-based word transformations.
- Word validation.
- Responsive mobile-friendly UI.
